Categraf Windows 7 / Server 2008 R2 采集包

基于官方 Categraf v0.3.87 源码，用 Go 1.20.14 编译，供仍在使用 Windows 7、Server 2008 R2、Server 2012 的环境接入夜莺。

源码与发行包：github.com/glj2369/categraf-win7-server2008

为什么需要这个包

官方从 v0.3.46 起改用 Go 1.21 出包，Windows 7 / Server 2008 R2 会报 kernel32.dll not found 或直接崩溃。更早的 0.3.45 虽能启动，接到夜莺 9.1 后平台、CPU、内存、网卡等元信息经常为空。

支持系统

  • 可用：Windows 7、Windows Server 2008 R2、Windows Server 2012（含 32 位）
  • 不可用：Windows Server 2008（非 R2）

下载

  • 64 位 zip
  • 32 位 zip

安装

改 conf/config.toml 的 [[writers]] 指向夜莺后执行：

categraf.exe --install
categraf.exe --start

升级不要覆盖已有 conf。换 exe 后执行 --stop --remove --install --start。
